# RuvNet Brain 4.7.28: verified defects, ranked

Code read: commit `0e7b9cfa` (4.7.28, equal to `origin/main`), from a clean export. Paths are relative to the
repository root at that commit. Nothing was run except small read-only checks; no test suite, build, install
or search was executed.

How each row was checked:
- **V** = the lead opened the cited line and read it.
- **R** = one of nine readers (Sonnet or Opus) reported it with the quoted line; the lead did not re-open it.
- **E** = taken from the earlier review (`../review/REVIEW.md`) and not re-opened in this run.

Severity: **Critical** = search is down, wrong answers ship, or code can reach users unchecked. **High** =
data loss, privacy, security exposure, or a control that does not do what it says. **Medium** = wrong or
misleading behaviour with a workaround. **Low** = untidy.

"Version 5 test" names the acceptance test in `ROADMAP.md` (S = walking skeleton, WP = work package) that
makes the defect impossible in the rewrite. The owner's decision is that 4.7.28 is not patched, so the
"one-line fix" column is for reference and for the one exception discussed in `ROADMAP.md` Part D.
