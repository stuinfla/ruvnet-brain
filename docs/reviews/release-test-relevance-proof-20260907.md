5. Harden the noted assertion-depth gaps only when making the corresponding proof claim: resealed semantic canary mutants, no-output checks, explicit stale-source qualification run. Existing digest-tamper tests are still valid.

No assertion here justifies retaining every historical repository test as a release gate.
