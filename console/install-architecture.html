RuvNet Brain · npx ruvnet-brain · install architecture

What's required, what's optional — and why the optionals earn their place.

The installer runs in your terminal. It always does the three required steps, asks about the two recommended ones (defaulting to yes), and leaves the rest off unless you opt in. Every item below maps to a real step in bin/install.mjs.

Required — the brain cannot answer without it Recommended — on by default, keeps it current & safe Optional — off by default, opt in when you want it

The core

Required · always runs

These are the product. Skip any one and there is nothing to answer questions with — so the installer does them without asking.

✓ Download the knowledge base

~736 MB, signature-verified, saved to ~/.cache/ruvnet-brain/kb. This IS the brain — rUv's whole stack, indexed.

bin/install.mjs · obtainBundle()

✓ Install the local reader

The engine that searches the brain on your machine — @ruvector/rvf + the local embedder. No API, nothing leaves your computer.

bin/install.mjs · installReader()

✓ Register the Claude Code plugin + MCP server

Wires search_ruvnet, the grounding hooks, and the /configure console into Claude Code. Without this the brain is on disk but Claude can't reach it.

bin/install.mjs · wirePlugin()

Keep it current & safe

Recommended · default yes

The installer asks, and pre-checks these. You can decline either — the core still works — but declining has a real cost, named below.

✓ Evergreen auto-update  ✓ verified running

A background job refreshes the brain as rUv ships. The "verified" tick comes from a real launchctl check — not from the box being ticked.

bin/install.mjs · offerNightly() · default YES

Decline and: updates become manual forever (npx ruvnet-brain --update). rUv ships fast, so a stale brain is the single biggest way this stops being useful.

✓ Spend watchdog

Warns you the moment an agent fleet runs away on API spend. Local, passive, no account access.

bin/install.mjs · spend-watchdog · default YES

Decline and: nothing watches for a runaway job. Fine if you never run paid fleets; cheap insurance if you might.

everything above is enough↓the rest is opt-in

Opt in when you want it

Optional · default off

Off unless you ask. Each is genuinely useful for a specific person — and pointless noise for everyone else, which is exactly why it's not on by default.

Add missing Ruflo / RuVector tools

Installs the orchestration + vector CLIs if you don't have them.

bin/install.mjs · offerStack() · default NO

Why optional: the brain answers grounded questions with zero loss without them. You only need them if you're going to run swarms or the vector CLI, not just ask about them.

Add a note to your CLAUDE.md

Appends a few lines nudging Claude to ground answers through the brain in every project.

bin/install.mjs · offerClaudeMd() · default NO

Why optional: the plugin's own hooks already do this. The note only matters if you skip the plugin — so for a normal install it's redundant, and editing your CLAUDE.md uninvited is exactly the "invisible virus" feeling to avoid.

Anonymous usage counts

A single version-ping so rUv can see adoption. No code, no prompts, no identity.

bin/install.mjs · --no-telemetry to decline

Why optional: it helps the project, helps you not at all — so it's a clean, one-flag opt-out and never buried.

Status-bar version segment

Shows the running brain version in your Claude Code status line.

bin/install.mjs · --statusline to enable

Why optional: pure preference — some people want the version in sight, most don't want another status-bar item. No reason to force either way.

The rule the whole installer follows: required things happen silently (asking would be theatre — nothing works without them), recommended things are asked with a default of yes and their cost-of-declining stated, and optional things stay off until you opt in, each with a reason it isn't on by default. High-impact background jobs (auto-update, spend watchdog) are never silently enabled by a blanket --yes — they always take a real answer.
